# 本地模型与启动

`abo_runtime/models/` 保存本机模型。Qwen3-VL-8B-Instruct 的官方权重共四片，运行时加载为 NF4。VisRAG-Ret 使用官方两片权重，在独立 Python 环境中计算查询和候选商品图向量。多语 E5 用于检索实验，日常目录使用 SQLite BM25。C 阶段 LoRA 保存在 `abo_runtime/reports/ecommerce_rag/stage-c-8b-120-20261110/adapter/`，程序按正式配置校验适配器摘要。

| PowerShell 启动参数 | 计算位置 | 用途 |
| --- | --- | --- |
| `-Command chat` | 本机 CPU | 目录、商品源字段、文本兼容 |
| `-Command chat -Gpu` | 本机 GPU | 以上功能及 Qwen 短寒暄、意图分类和源图问答 |
| `-Command chat -Visual` | 本机 CPU 与 GPU | BM25 召回后由 VisRAG-Ret 对至多六个候选的商品图重排 |
| `-Command cloud-chat` | Kaggle GPU | PowerShell 连接运行中的 Notebook，使用其模型和会话 |

## 从 GitHub 检出后配置

用 Python 3.11 在仓库根目录执行。通过本项目的私有发布 Dataset 取得 `abo-8b-formal.zip`，解包数据并构建目录。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-abo.txt huggingface-hub
.\.venv\Scripts\python.exe .\scripts\import_abo_assets.py --bundle .\abo-8b-formal.zip
.\scripts\run_abo.ps1 -Command check
```

为本机 Qwen 安装 CUDA 版 PyTorch 和模型依赖，再下载固定版本并核对官方文件摘要。若项目根目录有独立的 `.venv-gpu`，`-Gpu` 优先使用该环境。

```powershell
.\.venv\Scripts\python.exe -m pip install torch==2.8.0 torchvision==0.23.0 --index-url https://download.pytorch.org/whl/cu128
.\.venv\Scripts\python.exe -m pip install -r requirements-abo-gpu.txt
.\.venv\Scripts\python.exe .\scripts\download_abo_models.py qwen
```

为 VisRAG-Ret 创建独立环境。正式视觉重排需要 CUDA，实际候选取决于商品原图是否可取。

```powershell
python -m venv .\abo_runtime\.venv-visrag
.\abo_runtime\.venv-visrag\Scripts\python.exe -m pip install torch==2.1.2 torchvision==0.16.2 --index-url https://download.pytorch.org/whl/cu121
.\abo_runtime\.venv-visrag\Scripts\python.exe -m pip install -r requirements-visrag-ret.txt
.\.venv\Scripts\python.exe .\scripts\download_abo_models.py visrag
```

显存需求随图片分辨率、上下文和 GPU 上运行的其他程序而变。Windows 在 8 GiB 及以下 GPU 上对 Qwen 图像输入使用最多 262,144 像素的处理预算，商品原图和引用保留。运行记录保存视觉 token 数、显存和实际生成情况。需要查看更细的图像内容时，可以切到同项目的 Kaggle 入口。
