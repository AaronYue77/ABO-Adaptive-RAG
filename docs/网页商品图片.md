# 网页商品图片

商品目录、缩略图和原图来自 Amazon.com 和加州大学伯克利分校发布的 Amazon Berkeley Objects（ABO），素材遵循 Creative Commons Attribution 4.0 International 许可。 [ABO 官方数据页](https://amazon-berkeley-objects.s3.amazonaws.com/index.html) · [CC BY 4.0 许可](https://creativecommons.org/licenses/by/4.0/)

- 首页插图使用黑色背包和橙色手机壳的官方商品原图。项目缩小尺寸并转换为 WebP，网页用背景和旋转编排。 [黑色背包原图](https://amazon-berkeley-objects.s3.us-east-1.amazonaws.com/images/original/d2/d24c3671.jpg) · [橙色手机壳原图](https://amazon-berkeley-objects.s3.us-east-1.amazonaws.com/images/original/fb/fbef43f9.jpg)
- 类目优先用该类一条记录的主图，主图缺失时查同类记录的官方备用图。商品卡按同一条 ASIN@站点记录关联主图或备用图。可以在详情中打开 ABO 原图，查看源文件和行号。图片未载入时，商品名称和属性仍可打开。
- 回答中的图片由本轮候选或已核查的商品记录关联。比较价格、实时库存、政策或类目计数等回答不会因此插入商品图。仅打开图片的界面功能无需 GPU，模型读图问答沿用现有图像取证路径。
